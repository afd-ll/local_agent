# local_agent —— 让 4B 小模型干真活的正确姿势

一个运行在本地 Ollama 上的轻量 AI Agent。不依赖云端大模型，全部能力跑在自己机器上（CPU/GPU 都行）。

**为什么写这个**：云端 API 会涨价、内容会过第三方、断网就抓瞎。本地 4B 模型虽然"小"，但配合正确的工程结构——窄工具面、记忆沉淀、多步工具链、按需加载——能干的事远超想象。

## 功能

| 功能 | 说明 |
|---|---|
| 🧠 **记忆系统** | 跨会话持久化（JSON）；主动 `remember` + 对话裁剪时自动沉淀；超量自动压缩成长期记忆（调本地模型提炼） |
| 🔍 **联网搜索** | Tavily API（质量高），降级链：百度移动 → DuckDuckGo |
| 🛠 **6 个工具** | 列目录、执行命令（危险词拦截）、写文件（系统目录保护）、联网搜索、记住信息、打印 |
| 🔗 **多步工具链** | 自动规划："帮我记住设备信息" → 先查系统再记住 |
| ⏰ **时间感知** | 启动注入当前时间 + 距上次会话间隔 |
| 💫 **灵魂文件** | `soul.md` 定义身份/性格，启动注入 system，改文件即换人格 |
| ⏹ **Q 打断** | 流式输出时按 Q 立即停止 |
| ⏱ **耗时显示** | 每轮生成和每次工具调用显示耗时 |
| 🛡 **工具容错** | 工具执行出错不退出程序，错误汇报给 AI 决策 |
| 📜 **灰色思考** | qwen3 推理过程灰色显示，回答正常色，工具调用绿色 |
| 📐 **上下文管理** | 16K 窗口 + 滑动裁剪（裁剪前先沉淀进记忆，不丢早期内容） |

## 快速开始

```bash
# 1. 安装 Ollama 并拉模型
ollama pull qwen3:4b

# 2. （可选但推荐）注册 Tavily 免费 key（1000 次/月）
#    https://tavily.com
setx TAVILY_API_KEY tvly-你的key

# 3. 运行
python my_agent.py
```

## 配置

| 项 | 方式 |
|---|---|
| 模型 | 改代码 `MODEL` 常量（任意 Ollama 模型） |
| Tavily key | 环境变量 `TAVILY_API_KEY`（不设则降级百度/DDG） |
| 数据目录 | 默认 `~/.agent/`（记忆+灵魂放这里） |
| 指定记忆/灵魂文件 | `python my_agent.py [记忆文件路径] [灵魂文件路径]` |
| 灵魂设定 | 编辑 `~/.agent/soul.md`，重启生效 |

## 灵魂文件示例

```markdown
你是用户的 AI 助手，担任代码编写和闲聊的工作。
用户叫你小弟，你称呼用户为老大。
说话简洁自然，干活认真，像靠谱的搭档。
```

## 架构

```
用户输入
  → 系统提示（灵魂 + 时间 + 记忆注入 + 工具规则）
  → qwen3 思考（灰色显示）→ 流式输出
  → 需要工具？→ 执行工具（绿色显示）→ 结果回传 → 继续
  → 对话超 24 条？→ 早期对话沉淀进记忆 → 裁剪
  → 记忆超 20 条？→ 本地模型压缩成长期记忆 → 落盘
```

## 设计哲学

- **窄工具面**：小模型扛不住大工具集，6 个工具刚刚好
- **压缩不丢弃**：上下文裁剪前先提炼进记忆，早期信息以"记忆形态"存活
- **按需加载**：灵魂核心常驻、完整人格按需读文件、工具按需调用
- **不猜用户**：闲聊就是闲聊，需要工具时自然调用
